# 🎧 智能加速词汇音频生成系统 (极速缓存版)

这是一个基于 **FastAPI + Edge-TTS + Pydub (FFmpeg)** 构建的高性能双语词汇听力音频生成系统。系统专为语言学习者设计，支持将特定的
Markdown 格式词汇文本一键转换为标准的 MP3 听力文件，并**原生嵌入 LRC 动态同步歌词元数据**。

依托独特的**长期物理分片缓存机制**与并发安全写锁，当多次生成包含相同单词的配置时，系统会自动跳过网络请求，直接激活本地音频切片拼接，使二次生成速度飙升
**90% 以上**。

---

## ✨ 核心特性

* **⚡ 物理切片拼接技术**：采用 MD5 哈希对单个单词及音色组合进行长期物理缓存。相同词汇二次生成时抓取耗时无限趋近于 `0s`。
* **🔒 高并发安全防御**：内置分布式并发写锁（`asyncio.Lock`）与容量为 20 的高并发信号量控制，完美避免在极端多线程/高并发请求下导致的缓存踩踏与微软服务拦截。
* **🎼 丰富的自定义参数**：
    * **英文重复**：支持 1~5 次个性化循环朗读。
    * **音色组合**：内置多款高拟真微软原生音色（Aria/Guy/Sonia/Ryan/晓晓/云希），支持一键整包随机音色。
    * **语序模式**：支持按文本传统顺序生成，或乱序打乱（适合听写/自测场景）。
    * **内容模式**：支持英中混读（单词 + 中文释义）或纯英文朗读。
* **📝 原生内嵌动态歌词**：导出的 MP3 音频自带 `ID3v2 (USLT)` 动态同步歌词。支持在手机或电脑主流播放器中边听边看。
* **🎨 现代感流线前端**：基于 TailwindCSS 打造，内置完备的**引擎综合性能统计看板**以及实时滚动、高亮跟随的**动态歌词同步视窗
  **。

## 🛠️ 环境依赖与跨系统适配

本系统深度适配 Windows/Linux 环境，针对音频处理核心组件 **FFmpeg** 提供了多级智能动态检索：

1. **系统环境变量**：优先检测当前系统是否已配置并全局启用 `ffmpeg`。
2. **项目内嵌路径**：若系统无全局配置，自动检索项目根目录下 `./ffmpeg/bin/` 文件夹。
3. **本地备用路径**：自动兼容硬编码路径 `FFmpeg/bin`。

### 1. 基础环境安装

请确保本地已安装 Python 3.8+ 运行环境，在项目根目录下执行以下命令安装核心依赖：

```bash
pip install fastapi uvicorn edge-tts pydub mutagen tqdm WebSockets

```

### 2. FFmpeg 快捷配置 (以 Windows 为例)

FFmpeg<a href='https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-win64-gpl.zip'>下载链接</a>
若系统未配置 FFmpeg，您只需在项目根目录下创建一个名为 `FFmpeg` 的文件夹，并将下载好的 FFmpeg 核心程序放入其中。目录结构保持如下即可自动识别：

```text
你的项目根目录/
├── FFmpeg/
│   └── bin/
│       ├── ffmpeg.exe
│       └── ffprobe.exe
├── app.py
└── index.html

```
或者字形修改绝对路径


## 🚀 快速启动指南

### 1. 本地独立脚本运行 (`main.py`)

如果您不需要 Web 界面，只想在本地快速处理固定路径下的 Notion 导出的 Markdown 词汇文件：

* 打开 `main.py`，将 `MD_FILE` 变量修改为您的本地 `.md` 文件绝对路径。
* 在控制台运行：

```bash
python main.py

```

* 生成结果将按单元规范输出到 `output_audio/` 目录下，并自动附带 4 种（顺序/随机/纯英/混读）不同的模式组合。

### 2. FastAPI 极速 Web 服务运行 (`app.py`)

若要开启图形化 Web 界面，并享受性能看板和实时歌词滚动：

* 在控制台运行 Web 服务端：

```bash
python app.py

```

* 控制台提示成功后，在浏览器中访问：`http://127.0.0.1:8003`。

## 📋 Markdown 文本输入规范

为了保证系统能精准识别并剥离编号、短语变形及中文释义，请确保您上传的 `.md` 或 `.txt` 等文件符合以下标准格式（即*
*每行一个单词，末尾使用括号包裹中文翻译**）：

```markdown
# 单元 1：核心高频词汇

1. confidant(e) (n. 知己)
2. look (for) (v. 寻找，寻觅)
3. **priority** (n. 优先事项；优先权)
4. take measures to do sth (采取措施做某事)

```

> **💡 解析器高级兼容特性说明：**
> * 自动剥离行首的序号（如 `1.`、`2 ` 等）及加粗语法（`**`）。
> * 全面兼容中英文括号 `()` 与 `（）`。
> * 支持短语组合变形，例如检测到 `confident(e)` 或 `look(for)` 时，系统会自动扩展并优雅朗读为 `look, look for`。

## 🖥️ 页面操作快览

1. **上传文件**：将准备好的词汇文件拖拽或点击上传至配置面板。
2. **调整参数**：自由勾选循环次数、语序（顺序/随机）以及音色组合。
3. **精制音频**：点击“🚀 开始精制音频”，稍等片刻（若命中缓存，仅需 1 秒即可完成拼接）。
4. **视听同步**：生成成功后，点击下方控制台播放。右侧歌词视窗会随音频播放自动变色、放大并平滑滚动跟随。
5. **缓存管理**：如需彻底强制刷新或清理磁盘，可随时点击顶部的 **“🗑️ 清空后端所有 TMP 缓存”** 释放物理空间。
